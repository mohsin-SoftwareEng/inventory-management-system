# 📦 Inventory Management System

A Python-based **Inventory Management System** built using **Object-Oriented Programming (OOP)** concepts. It allows users to manage different types of products including Electronics, Clothes, and Food through a simple command-line interface.
## 🚀 Features

- ➕ Add Products (Electronics, Clothes, Food)
- ❌ Remove Products
- 🔍 Search Products by Name
- ✏️ Update Product Price & Quantity
- 💰 Get Total Inventory Value
- ⚠️ Get Low Stock Products
- 🖥️ Simple CLI Menu Interface
- ## 🛠️ Technologies Used

- **Language:** Python 
- **Concepts:** OOP, Inheritance, Abstract Classes (ABC)
- **Modules:** `abc` (Abstract Base Class)
  ## 📁 Project Structure

```
inventory-management-system/
│
├── product.py        # Product base class & subclasses (Electronics, Clothes, Food)
├── inventory.py      # Inventory class with all management functions
└── main.py           # Main file with CLI menu
